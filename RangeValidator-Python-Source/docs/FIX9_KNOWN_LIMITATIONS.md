# fix9의 확인된 한계

2026-11-11 독립 경계 검사에서 아래 사항을 재현했습니다. 제출용 정리는 기능 수정이나 수정 완료 검증을 의미하지 않습니다.

- 음수가 있는 enum 비트필드를 unsigned로 가정해 MATCH/MISMATCH를 잘못 판정할 수 있습니다.
- unsigned 정수의 순환 연산을 C의 정수 타입 규칙대로 계산하지 못해 범위를 잘못 비교할 수 있습니다.
- 같은 파일에 함수가 조건 없이 중복 정의돼도 후보 범위가 같으면 확정 판정으로 이어질 수 있습니다.
- 값이 같은 매크로의 표기가 다르거나 선언 후 매크로가 재정의되는 경우 불필요한 REVIEW가 발생할 수 있습니다.
- `0~7.0`처럼 정수값을 소수로 적은 끝점을 정수 구간과 동등하게 처리하지 못합니다.
- `(*p).member`, `(p)->member` 같은 일부 표현식이 REVIEW도 남기지 않고 결과에서 빠질 수 있습니다.

이 도구는 비트필드의 표현 가능 범위를 비교합니다. 함수에서 실제 사용하는 값이나 업무상 제한 범위의 적절성을 증명하지 않습니다. 대상 컴파일러의 전체 문법·ABI·확장 및 모든 Excel 양식을 지원하는 것은 아닙니다. 실제 회사 프로젝트 원본 전체에 대한 검증은 수행하지 않았습니다.
