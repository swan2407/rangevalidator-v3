# 6-2 합성 EXE 통합 점검 실행

이 폴더의 데이터는 테스트가 만든 합성 C/H·XLSX이며 회사 자료를 사용하지 않습니다.

명시적 실행 명령은 다음과 같습니다.

    RangeValidator.exe --full-integration-test C:\Range\RangeValidator-Python-Source\build\acceptance-6-2.json

수신 JSON 경로의 확장자를 제거한 폴더를 새로 생성합니다. 재실행 시 새로운 JSON 경로를 지정해야 기존 결과를 보존할 수 있습니다.
테스트는 두 합성 원본 파일을 생성하고 실제 Excel COM Reader와 Writer를 사용합니다.
Tk 앱의 큐와 콜백을 구동하지만, 파일 선택·수동 입력 대화상자에 사람이 입력한 것과 동일한 검증은 아닙니다.
수동 선택 모델에는 테스트가 명시적으로 ReviewRequest를 전달합니다.

확인 범위는 네 판정 상태, GUI 파일·시트 이동 및 필터·검색 콜백, 100% 진행률,
세 수정 유형 동시 저장, 수식·병합 제외, COM 재열기 값 확인, 원본 바이트 동일성,
보고서 시트/필터/헤더 및 실제 이력, 기존 출력 파일 충돌의 파일별 격리입니다.

원본 읽기와 저장본 확인은 실제 COM입니다. 합성 XLSX 생성 및 결과 보고서 확인에는 openpyxl을 사용합니다.
읽기 전용 설치 경로, 별도의 Python 미설치 PC, 사용자의 기존 Excel 창과의 공존은 별도 확인이 필요합니다.
회사 DRM·보안 설정은 변경하지 않습니다.
